## English

### Product name

Waller

### Short description

Create, save, and apply independent wallpapers and placement settings for every Windows monitor.

### Full description

Waller is a native Windows wallpaper manager built for multi-monitor desktops.

Create one active session, assign a different local image or solid color to each connected monitor, choose the placement that fits each screen, and save reusable presets. Waller renders a shell-readable result for every monitor and applies the complete setup through Windows desktop wallpaper APIs.

Save and Apply remain separate. Save stores a reusable preset without changing the desktop. Apply renders and changes the current wallpaper configuration, with clear progress, cancellation, and error feedback.

Waller is local-first. It does not require an account and is not designed to upload wallpaper images, file paths, presets, monitor information, or settings.

### Features

- Independent wallpaper source per monitor
- Local images, solid colors, and empty assignments
- Cover, Contain, Stretch, Center, and Tile placement
- Reusable local presets
- Save, load, rename, duplicate, and delete preset workflows
- Per-monitor render output compatible with the Windows shell
- Apply progress, cancellation, and clear error feedback
- English interface
- Light and dark appearance
- Keyboard-accessible native Windows UI

- English UI

## Español

### Nombre del producto

Waller

### Descripción breve

Crea, guarda y aplica fondos y ajustes de colocación independientes para cada monitor de Windows.

### Descripción completa

Waller es un gestor nativo de fondos de pantalla para escritorios con múltiples monitores en Windows.

Crea una sesión activa, asigna una imagen local o un color distinto a cada monitor conectado, elige la colocación adecuada para cada pantalla y guarda presets reutilizables. Waller renderiza un resultado legible por el shell para cada monitor y aplica la configuración completa mediante las APIs de fondos de Windows.

Guardar y Aplicar son acciones independientes. Guardar almacena un preset sin cambiar el escritorio. Aplicar renderiza y modifica la configuración actual, mostrando progreso, cancelación y errores de manera clara.

Waller funciona de forma local. No requiere una cuenta y no está diseñado para subir imágenes, rutas, presets, información de monitores ni ajustes.

### Funciones

- Fuente de wallpaper independiente por monitor
- Imágenes locales, colores sólidos y asignaciones vacías
- Modos Cover, Contain, Stretch, Center y Tile
- Presets locales reutilizables
- Guardar, cargar, renombrar, duplicar y eliminar presets
- Renderizado por monitor compatible con el shell de Windows
- Progreso de aplicación, cancelación y errores claros
- Interfaz en inglés
- Apariencia clara y oscura
- Interfaz nativa accesible mediante teclado

### Novedades

Primera publicación de Waller en Microsoft Store.

- Flujo nativo WinUI para múltiples monitores
- Gestión local de presets
- Renderizado y colocación por monitor
- Interfaz en inglés

# Screenshot provenance

Updated 2026-08-15.

The four product captures were recorded from the real WinUI application using a temporary, self-contained proof package. Its detector supplied three fictional displays (`Studio display`, `Portrait review`, and `Notes display`) so no personal monitor name, wallpaper path, preset, or setting entered the images.

The proof package used `docs/assets/examples/field-route-wallpaper.png`, an original Imagegen asset created for this maintenance pass. It has no text, logo, glow, or third-party source material. Waller never applied the fixture to Windows; Save and Apply remained untouched. The proof process was stopped and its temporary AppX registration was removed after capture.
